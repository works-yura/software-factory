# Глосарій перекладу UI (EN → UK)

Перекладаємо **зміст**, а не англійське слово. Фабрика — це інструмент розробника: тон діловий, короткий, без канцеляриту. Звертання на «ви», у кнопках — інфінітив або наказовий спосіб без займенника («Зберегти», «Запустити»).

## Етапи дошок

Id етапу ≠ англійський підпис в UI: `execute` в UI підписано «Building», але перекладаємо за змістом.

## Не перекладати

Назви продуктів і сервісів (GitHub, GitLab, Mastra, Claude, OpenAI), імена моделей, гілки, команди, шляхи, id, коди помилок, текст від сервера, вміст, який написав користувач чи агент.

## Технічні правила

- Англійський текст у каталозі має **точно** дорівнювати рядку, який був у коді: тести UI перевіряють англійську.
- Множина: ключі `_one`/`_other` в англійській, `_one`/`_few`/`_many`/`_other` в українській; виклик з `{ count }`.
- Підстановки: `{{name}}`, без склеювання рядків з частин речення.
- Дати й числа: локаль поточної мови (`currentLanguage()`), а не `undefined`.
