# Налаштування Factory, що змінюють поведінку агентів

## Мова агентів

Рішення: [ADR-0008](../../adr/0008-agent-language.md).

- «Налаштування › Моделі», під перемикачем harness: «Українська» / «English»; типово українська, і для наявних Factory (колонка `agent_language`, типово `uk`).
- Сервер додає рядок мови в системні інструкції кожної сесії обох harness — карток, звичайних чатів і чату Factory; мова читається щоходу. Код, ідентифікатори, шляхи, команди, цитати й тексти для клієнта лишаються своєю мовою.
- Сесія без Factory рядка не отримує; Factory, яку не знайдено, — помилка ходу, а не тиха відповідь без мови.

## Де в коді

- `packages/server/src/agent-language.ts`; Mastra — `hostInstructions` у `packages/server/src/factory.ts`; Claude Code — `appendSystemPromptFor` у `packages/server/src/claude/harness.ts`.
- Збереження: `packages/store/src/projects/base.ts`; контракт: `packages/contracts/src/contracts.ts`.
- UI: `apps/ui/src/ui/domains/settings/components/models/AgentLanguageSection.tsx`.

## Розділ «Підключення»

Рішення: [ADR-0031](../../adr/0031-connections-one-list.md) (раніше «Інтеграції» з вкладками, [ADR-0027](../../adr/0027-integrations-services-and-mcp.md)). Шлях лишився `/settings/integrations`, група «Factory».

- **Заголовок** (`ConnectionsPageHeader.tsx`): «Підключення» і «+ Додати підключення» (`?add=1`); на сторінці підключення — «← Підключення», логотип, назва, значок стану. **Сторінка підключення** — вкладки «Огляд», «Активність», «Доступ», «Інструменти», «Налаштування», «Діагностика» (`&view=`), див. ADR-0031, доповнення 3.
- **Підключення належать організації** (ADR-0031, доповнення 4): меню ClickUp, GitHub (рядок на встановлення), GitLab — «Перейменувати», «Перепідключити», «Видалити підключення»; що зробити не можна (токен у середовищі сервера, Platform, не адміністратор; GitHub, поки його репозиторії в проєктах) — вимкнено з причиною. Google Cloud і MCP мають ще «Відв'язати від Factory» — це доступ Factory, не окреме підключення.
- **Список Factory** (`components/connections/ConnectionsSection.tsx`, `ConnectionList.tsx`, таблиця кіта; на телефоні — складені рядки): інтеграція (позначка MCP), акаунт, можливості, стан, меню «⋮» — «Відкрити», «Перепідключити», «Перейменувати», «Відв'язати від Factory», «Видалити з організації» (що дозволяє вид). Рядки будує `connections/connections.ts` зі стану інтеграцій: прив'язки Google Cloud цієї Factory (з «Базою» в тому ж рядку), MCP-сервери з доступом цієї Factory, ClickUp / GitHub / GitLab на всю організацію.
- **Рядок відкриває свою сторінку** (`?connection=google-cloud:<прив'язка>|mcp:<сервер>|mcp-new:<запис каталогу>|google-cloud|clickup|github|gitlab`, `ConnectionDetail.tsx`) з наявними налаштуваннями: [google-cloud](../google-cloud/design.md), [mcp-servers](../mcp-servers/design.md), ClickUp (токен організації: «Підключити» / «Замінити токен» / «Відключити» — лише адміністратору, [ADR-0032](../../adr/0032-integration-tokens-belong-to-organization.md); `ClickUpService.tsx`), GitHub, GitLab (`SourceControlServices.tsx`). `&account=<id>` відкриває нову прив'язку через цей акаунт.
- **«Додати підключення»** (`AddConnectionDialog.tsx`, кроки — `ConnectSteps.tsx`): `Dialog` `md` з `Command` кіта — пошук і «Усі / Інструменти / Джерела» в одному рядку (`CommandInput rightSlot`), список у `ScrollArea`, рядки `CommandItem` з клавіатурою; розділи «Акаунти організації» (під'єднати акаунт Google Cloud чи MCP-сервер), «Інтеграції» (Google Cloud, ClickUp, GitHub, GitLab — логотип і значки можливостей) і «Інше» («Власний сервер MCP», сторонні записи каталогу). Інтеграція першої сторони відкриває крок «Підключити X» у тому ж вікні: Google Cloud — акаунт або новий ключ з поступом, помилкою («Не вдалося підключити», «Спробувати знову») і успіхом; ClickUp / GitHub / GitLab — стан і їхні керування. Записи каталогу, які запускає інтеграція (`entry.integration`), не пропонуються. Логотипи — `simple-icons` (`ConnectionIcon.tsx`).
- **«Активність»** (`ConnectionActivity.tsx`): виклики MCP цієї Factory за 24 години (`GET /web/mcp-servers/activity`).
- **Телефон:** рядки складаються в картки; «Додати підключення» — на весь екран з відступами безпечної зони; кнопки ≥ 44 px; без горизонтальної прокрутки.
- Старі `?tab=…&service=…`, `/settings/observability` і `/settings/mcp-servers` переводять сюди (`RETIRED_SETTINGS_SECTIONS`, `connectionsPath`, `settingsSections.ts`); «Репозиторії» — лише вибір репозиторіїв, «Надходження задач» — лише маршрути.

## Розділ «Середовище»: змінні й env-файли

Рішення: [ADR-0026](../../adr/0026-env-files-and-sandbox-stages.md). Імпорт зроблено за зразком панелі змінних Mastra platform (projects.mastra.ai, закритий код — лише за знімком екрана).

- **«Додати або імпортувати»** (`environment/ImportSandboxEnvsDialog.tsx`) — єдиний шлях додати змінні; «Редагувати» в рядку лишається для однієї змінної. Вкладки «Форма» (рядки назва/значення) і «Текст» (зона `FileDropZone` кіта — перетягнути файл або «Вибрати файл», до 256 КБ, і поле «Вміст .env»); «Де діє» (Build/Runtime) і стадія — на всі змінні імпорту.
- **Розбір** (`environment/dotenv.ts`): коментарі, `export`, лапки (зокрема багаторядкові), `=` у значенні, порожні значення. На відміну від `parseEnvFileText` кіта, нічого не відкидається мовчки: рядок без `=`, без назви, незакрита лапка чи текст після неї — у списку «не можна імпортувати» з номером рядка (без значення).
- **«Переглянути змінні»** — таблиця рядок / назва / значення (замасковане) / стан: «Нова», «Перезапише наявну», «Повтор: діє рядок N» (діє останній), назва чи значення, які сервер відкине (ті самі правила, що `sandboxEnvNameSchema`). Нічого не надсилається до «Зберегти N змінних».
- **Збереження** — по одному `PUT …/sandbox-envs/:name` (пакетного API немає), послідовно; після часткової невдачі вікно лишається з результатом кожного рядка й кнопкою «Повторити невдалі» (лише вони).
- **Env-файл** (`environment/RepositoryEnvFiles.tsx`): та сама `FileDropZone` — будь-який текстовий файл (напр. `.json` сервісного акаунта) заповнює вміст, а порожній шлях — назвою файла (правила шляху показують, якщо назва не підходить). Вміст файла прихований («Показати вміст»). Ліміт — серверний `MAX_SANDBOX_ENV_FILE_CONTENT_LENGTH` (64 КБ символів), більший файл чи двійковий (NUL) — помилка під зоною.
