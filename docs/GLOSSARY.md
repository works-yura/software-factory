# Factory

Фабрика агентів для розробки клієнтських проєктів: дошки ведуть роботу від ідеї до PR, агенти працюють у пісочницях карток.

## Мова

**Factory (фабрика)**:
Середовище для одного набору репозиторіїв: пісочниця, моделі, ключі, налаштування (`FactoryProject`).
_Уникати_: проєкт (у UI), воркспейс

**Дошка**:
Процес із фазами й воротами, заданий кодом (`defineBoard`): «Продукт», «Розробка».
_Уникати_: пайплайн, борд

**Картка**:
Одна задача чи зміна на дошці (`WorkItem`).
_Уникати_: тікет, issue

**Фаза**:
Колонка дошки зі своїм скілом і контекстом сесії.
_Уникати_: стадія, етап

**Контекст сесії**:
Ключ сесії картки (`triage`, `work`, `review`, `product`); кілька фаз можуть ділити один контекст.

**Сесія**:
Розмова з агентом на одному harness з власним тредом; у картки — одна сесія на контекст.
_Уникати_: тред, чат (для сесії картки)

**Harness**:
Рушій, на якому працює сесія: Mastra або Claude Code.

**Скіл**:
Інструкція агенту на кроці (`SKILL.md` + `references/`).

**Пісочниця**:
Робоча папка картки з checkout репозиторіїв; спільна для сесій картки.

**Ворота**:
Умова переходу між фазами, яку перевіряє дошка (наприклад, `factory_check_product_document` пройшла).

**Бриф**:
Нетехнічний документ для клієнта: що й навіщо будуємо, межі оцінки, оцінка в годинах (`requirements.md`).
_Уникати_: ТЗ, PRD

**Специфікація**:
Технічна дельта для команди: як зміна вбудовується в систему (`changes/<зміна>/design.md`).
_Уникати_: дизайн-документ

**Зміна**:
Одна картка «Продукту» і її папка `changes/<дата>-<зміна>/`.

**Правда області**:
`features/<область>/design.md` — як область працює зараз.

**Межі оцінки**:
Розділ брифу: що оцінка не покриває і чому.
_Уникати_: не входить, out of scope

**Вкладення**:
Файл картки чи сесії в сховищі вкладень (`factory_attachments`).

**Посилання (в чаті)**:
Сесія чи картка, вкладена в повідомлення; вид — запис реєстру `refKinds`.

**Мова агентів**:
Налаштування Factory: якою мовою агенти пишуть людині й команді.
