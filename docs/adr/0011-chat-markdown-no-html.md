# 0011. Чат показує лише Markdown; скіли не пишуть HTML у чат

Дата: 2026-11-10 · Статус: прийнято · Коміт: `0248e95`

**Контекст.** Розбір писав у чат той самий текст, що й у коментар GitHub, з `<details><summary>`; чат показував сирі теги. Рендерер (`MarkdownRenderer`, react-markdown + remark-gfm) свідомо не виконує HTML — так і в оригіналі Mastra.

**Рішення.** Рендерер не змінюємо. Скіли пишуть у чат звичайним Markdown: заголовки `###` замість `<details>`, жодного HTML.

**Наслідки.** Новий скіл, що пише в чат, не використовує HTML.

**Альтернативи.** Дозволений набір тегів у рендерері — почато й зупинено: ховає причину і відкриває шлях HTML у чат.
