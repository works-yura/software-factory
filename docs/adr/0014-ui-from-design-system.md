# 0014. UI будується з частин дизайн-системи

Дата: 2026-11-10 · Статус: прийнято · Коміти: `63ac5bb`, `1fec164`, `03b895f`, `dd4aec8`

**Контекст.** Кілька елементів спершу зробили окремо (картка кількох питань, нотатка на виділеному тексті, чипи посилань); вони відрізнялись від решти інтерфейсу й дублювали готові частини.

**Рішення.** Новий елемент складається з частин `packages/playground-ui` (дизайн-система з Mastra): питання — `AskUser.*`, нотатки — `annotations`, вкладення й посилання — `ComposerAttachment` / `AttachmentCard`. Якщо частини бракує, її додають у дизайн-систему поруч із наявними, а `apps/ui` лишає тонкий адаптер. Тексти дизайн-системи перекладаються через `libText` і каталог `apps/ui/src/ui/i18n/library/`.

**Альтернативи.** Окремі компоненти в `apps/ui` — відкинуто: різний вигляд і дублювання.
