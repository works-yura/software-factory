# 0007. Задача береться з картки (ClickUp), не з GitHub issue

Дата: 2026-11-10 · Статус: прийнято · Коміт: `0248e95`

**Контекст.** Скіли `factory-*` перенесені з Mastra, де задачі — GitHub issues: мітки `status: …`, коментар-маркер із `<details>`, підрахунок PR автора, скіл `factory-complete-issue`. У нас задачі приходять лише з ClickUp (intake створює картки) або заводяться вручну; GitHub — тільки для коду й PR.

**Рішення.** Розбір, план, самоперевірка й рев'ю беруть задачу з картки Factory (назва, опис, коментарі; текст таски ClickUp приходить туди). Розбір пише висновок у чат звичайним Markdown. План зберігається в `.artifacts/plans/<card-id>.md`. Скіл `factory-complete-issue` і його запуск на «Готово» видалено. Робота з PR на GitHub лишилась.

**Наслідки.** Відхилення від upstream записано в `MIGRATION.md` («Задачі з карток, не з GitHub issues»). Інструментів ClickUp для агента (коментар, статус таски) поки нема — `changes/backlog.md`.

**Альтернативи.** Лишити GitHub-гілки скілів «про запас» — відкинуто: мертві шляхи, які агент усе одно пробує.
