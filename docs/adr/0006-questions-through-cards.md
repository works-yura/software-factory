# 0006. Кожне питання до людини — карткою питань

Дата: 2026-11-10 · Статус: прийнято · Коміти: `aad3edf`, `93272ff`, `088e910`, `63ac5bb`, `1fec164`, `ae9b262`, `f1ca470`, `ff235d7`, `d85a2ce`

**Контекст.** Агенти ставили питання текстом у кінці довгого повідомлення; людина їх пропускала або відповідала не на все, а «бухгалтерські» питання (куди класти файл) відволікали.

**Рішення.** Кожне питання до людини — прогалина, вибір, підтвердження, «далі?» — через інструмент питань: `AskUserQuestion` у Claude Code (до 4 питань одним викликом), `ask_user` у Mastra (по одному). Рекомендований варіант — першим; власна відповідь — один із варіантів. Кілька питань показуються однією карткою `AskUser.Questions` з дизайн-системи. Бухгалтерію агент робить мовчки. На кожну нотатку людини агент відповідає за її номером.

**Наслідки.** Питання простим текстом — дефект скілу. Картка, на яку сесія зараз не чекає, вимкнена.

**Альтернативи.** Питання вільним текстом — відкинуто з причин вище.
