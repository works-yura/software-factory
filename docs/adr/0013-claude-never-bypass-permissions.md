# 0013. Claude Code harness ніколи не обходить дозволи

Дата: 2026-10-27 · Статус: прийнято · Коміт: `687eaaa`

**Контекст.** Сесії Claude Code працюють з реальними репозиторіями клієнтів і секретами.

**Рішення.** Harness ніколи не запускає CLI з `bypassPermissions` чи `--dangerously-skip-permissions`: `packages/harness-claude-code-core/src/cli.ts` кидає помилку. Дозволи йдуть через правила фабрики (allow / ask / deny) і підтвердження в чаті; налаштування й MCP-сервери людини в сесію не потрапляють.

**Альтернативи.** Режим без підтверджень — відкинуто.
