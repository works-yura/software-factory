# 0008. Мова агентів — налаштування фабрики, типово українська

Дата: 2026-11-10 · Статус: прийнято · Коміт: `4cab16e`

**Контекст.** Скіли написані англійською, тому плани й звіти виходили англійською, хоча команда працює українською. Лише Product-скіли мали мову прописаною.

**Рішення.** Factory має налаштування «Мова агентів» (`uk` / `en`, типово `uk`, колонка `agent_language`). Сервер додає один рядок у системні інструкції кожної сесії — обох harness, усіх дошок і чату: писати людині й команді цією мовою; код, ідентифікатори, шляхи, цитати й тексти для клієнта лишаються своєю мовою. Мова читається щоходу. Місце — не скіли, а `packages/server/src/agent-language.ts`, `factory.ts` (Mastra), `claude/harness.ts` (Claude Code).

**Наслідки.** Чи підхоплює нову мову вже запущена сесія Claude Code — не перевірено (`changes/backlog.md`).

**Альтернативи.** Правило мови в кожному скілі — відкинуто: дублювання, і скіли з upstream.
