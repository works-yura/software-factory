# 0052. Артефакти — те, що агент зробив для людей

Дата: 2026-11-16 · Статус: запропоновано (план, не зроблено)

**Контекст.** Людина просить у будь-якому промпті «дай APK», «зроби звіт покриття», «запиши відео прогону» — і хоче отримати файл, який можна відкрити чи скачати, навіть коли пісочницю вже видалено. У CI (GitHub Actions) артефакти оголошують заздалегідь шаблоном шляху (`build/**/*.apk`). В агента інакше: він сам вирішує, що варто показати, як в артефактах Claude. Перший крок уже є: `factory_attach_file` кладе файл з теки сесії у вкладення картки (джерело `agent`, «Від агента»), звідки його скачують з «Файлів». Але вкладення — вхідні матеріали (бриф, скріншоти клієнта), а не результат роботи: у них немає коміту, гілки, статусу збірки, журналу, свого ліміту й чистки.

**Рішення (план).**
- **Артефакт — окремий запис**, не вкладення: файл (назва, тип, розмір, sha256) або лише журнал, коли збірка впала; репозиторій, гілка, коміт (SHA) і позначка незакомічених змін — їх сервер бере сам з чекауту сесії від імені агента, а не зі слів агента; версія (необов'язково, агент читає `pubspec.yaml`, `package.json`); статус (успіх чи помилка) і журнал збірки; хто попросив, яким агентом, коли; картка або сесія без картки.
- **Сховище під великі файли.** Окрема тека й ліміт (`FACTORY_ARTIFACTS_DIR`, `FACTORY_ARTIFACTS_MAX_BYTES`, типово 500 МБ), той самий адаптер, що й у вкладень (`AttachmentBlobStore`, ключ — sha256). Чистка: останні N (типово 10) на репозиторій + гілку + назву; N — налаштування Фабрики.
- **Інструмент агента** `factory_publish_artifact({ path, name?, version?, status?, logPath? })` у кожній сесії (Mastra, Claude Code; далі Codex, OpenCode через MCP). Інструкція агенту: що людина захоче побачити чи скачати — публікуй як артефакт. Байти читає пісочниця своїми командами, з правами агента (`openSessionFile`, як у `factory_attach_file`). У чаті — картка артефакту з «Завантажити».
- **Де видно.** Вкладка «Артефакти» на картці (окремої дошки немає): найновіші зверху, групи за гілкою, SHA, статус, розмір; клік відкриває (картинки, PDF, HTML — одразу), будь-який файл скачується.
- **`factory_attach_file` стає `factory_publish_artifact`**; джерело `agent` у вкладеннях переходить в артефакти.

**Поза цим кроком.** Шаблони шляхів, як у CI, у налаштуваннях репозиторію (Фабрика сама забирає файли після ходу агента); підпис збірок (keystore як секрет Фабрики); встановлення на телефон (посилання/QR, TestFlight, Firebase App Distribution).
